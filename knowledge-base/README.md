## 系统定位
围绕**北海为中心**，整合**陆地 · 海洋 · 卫星 · 天文 · 空气质量**五大数据域，提供：
- 全方位权威**实时天气**（陆地 / 空气 / 海洋 / 天文 / 潮汐）
- **周期预报**（7 日 + 24h 逐时）
- **极端天气 / 景观告警**（地震 · 汛情 · 干旱 · 高温 · 台风 · 野火 · 风暴潮 + 黄昏霞光）
- **地图全景**：真实北海边界 + 风险着色 + 台风 / 地震 / 火点 / 潮汐图层 + 卫星云图 / 雷达叠加
- **顶部自动播报情报条** + **左栏标红告警清单**，均标注「涉及北海 / 可能涉及北海」与「距北海」距离

服务于北海防风防汛、防灾应急、海岛作业窗口判断与夜巡排班参考。

## 技术栈
- **后端**：纯 Node.js（`http` + `fetch`，零第三方依赖），单文件聚合 `server.js` + `lib/*`
- **前端**：暗色响应式三栏仪表盘 + Leaflet 地图 + Chart.js，原生 JS，无构建步骤
- **数据源适配层** `lib/sources.js`：失败降级不阻塞整体；统一 `/api/overview` 聚合 + 分项接口，`Promise.allSettled` 容错，自动 10 分钟刷新
- **坐标合规**：内置 WGS-84 → GCJ-02 变换；演示底图用高德(Amap) 栅格瓦片（GCJ-02，国内直连稳定、免密钥）
