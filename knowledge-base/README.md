## 系统定位

最新 v8.2.0 已集成**江河水文 · 水库水情模块**：内置北海主要江河（南流江等 8 条）与水库（洪潮江、牛尾岭等 5 座）权威档案，看板新增「江河水文」「水库水情」两面板（降级为档案展示，界面明确标注非实时）。
围绕**北海为中心**，整合**陆地 · 海洋 · 卫星 · 天文 · 空气质量**五大数据域，提供：
- 全方位权威**实时天气**（陆地 / 空气 / 海洋 / 天文 / 潮汐）
- **周期预报**（7 日 + 15 日 + 24h 逐时）
- **极端天气 / 景观告警**（地震 · 汛情 · 干旱 · 高温 · 台风 · 野火 · 风暴潮 + 黄昏霞光）
- **地图全景**：真实北海边界 + 风险着色 + 台风 / 地震 / 火点 / 潮汐图层 + 卫星云图 / 雷达叠加
- **世界时钟**：机械钟 + 数字钟（毫秒精度）+ 设备/北京/国际时区 + 对时
- **顶部自动播报情报条** + **左栏标红告警清单**，均标注「涉及北海 / 可能涉及北海」与「距北海」距离
- **模块点击放大**、**深 / 浅色主题**、**声音警报**

服务于北海防风防汛、防灾应急、海岛作业窗口判断与夜巡排班参考。

## 关键位置
- 可运行系统（技能包）：`app/`（入口 `app/server.js`）
- 单文件 exe：Windows / Linux / macOS 由 CI 在推送 `main` 后自动构建并发布到 **GitHub Release（`releases/latest/download/`，始终最新）**，或本地 `npm run build:exe` 生成（输出 `app/dist/`）
- 技能定义：`SKILL.md`
- 完整文档（本目录）：`knowledge-base/`
- 运行入口：浏览器打开 `http://localhost:8765`（`node server.js`，默认端口 8765）

## 技术栈
- **后端**：纯 Node.js（`http` + `fetch`，零第三方依赖），单文件聚合 `server.js` + `lib/*`
- **前端**：暗色 / 浅色响应式三栏仪表盘 + Leaflet 地图 + Chart.js，原生 JS，无构建步骤
- **数据源适配层** `lib/sources.js`：失败降级不阻塞整体；统一 `/api/overview` 聚合 + 分项接口，`Promise.allSettled` 容错，自动 10 分钟刷新
- **坐标合规**：内置 WGS-84 → GCJ-02 变换；演示底图用高德(Amap) 栅格瓦片（GCJ-02，国内直连稳定、免密钥）
