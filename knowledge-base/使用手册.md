> 版本 v7.0.1 ｜ 作者：阳光（net2net2net）

## 1. 运行方式

### 1.1 作为独立软件（推荐，零依赖）
- **Windows**：双击 `D:\SynologyDrive\Skills\alphasun-beihai-climate\app\start.bat` → 自动启动并打开浏览器 `http://localhost:8765`
- **Linux / macOS**：终端执行 `bash app/start.sh`
- 包内 `app/node/node.exe` 为内置便携 Node 运行时，**无需预装 Node.js**。

### 1.2 由智能体运行（已安装技能）
技能加载后，在技能包 `app/` 目录执行：
```bash
cd <技能根>/alphasun-beihai-climate/app
PORT=8765 node server.js
```

### 1.3 开发模式（最新源码）
```bash
cd E:\SD\SynologyDrive\Workspace\2026-08-25-09-48-56\alphasun-weather
node server.js        # 默认端口 8765
```

### 关键交互
- **顶部横幅 / 左栏告警**：点击任一告警 → 弹出详情（区域、距北海、发布时间、坐标、处置建议、北海关联徽标）。
- **情报条**：默认自动滚动；▶⏸ 暂停/恢复；▲▼ 手动翻页；点击卡片弹详情。
- **全景地图**：右上角图层开关可叠加 卫星云图 / 雷达拼图 / 降水 / 风力 / 温度 / 扰动 / 风场 / 海浪 / 副高（实况+预报）；台风/地震/火点/预警弹窗显示「距北海约 X km」。
- **推荐站点**：地图下方分类列出官方机构 / 数据源 API / 可视化叠加源，点击新窗口打开。

## 3. 环境变量
| 变量 | 作用 | 默认值 |
|------|------|--------|
| `PORT` | 服务端口 | `8765` |
| `FIRMS_MAP_KEY` | 激活 NASA FIRMS 火点图层 | 未设则火点降级关闭 |
| `NMDIS_APPID` / `NMDIS_APPSECRET` | 激活国家海洋信息中心权威潮汐/水位 | 未设则调和模型估算（演示） |

示例：
```bash
FIRMS_MAP_KEY=xxxx NMDIS_APPID=yyy NMDIS_APPSECRET=zzz PORT=9000 node server.js
```

## 4. 常见问题

**Q1：打开页面是空白 / 灰屏？**
- 底图为高德(Amap) 栅格瓦片，需能访问国内网络；离线环境会降级为 CartoDB/OSM（WGS-84）。
- 确认服务已启动：`curl http://localhost:8765/` 应返回 HTML。

**Q2：叠加卫星云图/雷达没图？**
- nmc 卫星云图（风云 FY2G）与雷达拼图已实测可叠加；其余中央台产品页为 JS 动态渲染，勾选时若取图失败会提示并保留官方原图 `↗` 链接（不伪造坏图）。
- RainViewer / NASA GIBS 随外网可用性降级。

**Q3：火点 / 权威潮汐不显示？**
- 火点需配置 `FIRMS_MAP_KEY`；权威潮汐需配置 `NMDIS_APPID/APPSECRET`；未配置时分别以关闭 / 调和模型估算（演示）兜底。

**Q4：端口被占用？**
- 用 `PORT=新端口 node server.js` 覆盖；或在 Windows 用 `netstat -ano | findstr :8765` 查进程并释放。

**Q5：数据多久刷新？**
- 实时 10 分钟自动刷新；界面可手动刷新。部分权威源本身更新频率有限，界面标注「数据时间」。
