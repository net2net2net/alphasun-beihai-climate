# AlphaSun · 北海极端气候全景系统 — 使用手册

> 版本 v8.2.0 ｜ 作者：阳光 net2net2net（ Vx: net2net ）

## 1. 运行方式

### 1.1 作为独立软件（推荐，零依赖）
- **单文件 exe（最简单）**：从 **GitHub Release（`releases/latest/download/`，CI 自动发布，始终最新）** 取 Windows / Linux / macOS 单文件 exe → 双击（或 `./alphasun-beihai-climate-linux`）运行 → 浏览器自动打开 `http://localhost:8765`，关闭黑色控制台窗口即停止。**exe 已内置 Node 运行时，无需 Node.js、无需任何外部文件**（约 84–120MB 各平台，内置 Node 运行时 + 全部前端资源）。可选环境变量：`PORT=9000` 改端口；`OPEN=0` 禁止自动开浏览器。
- **Windows**：双击 `app/start.bat` → 自动启动并打开浏览器 `http://localhost:8765`
- **Linux / macOS**：终端执行 `bash app/start.sh`
- 单文件 exe 已内置 Node 运行时，**无需预装 Node.js**；完整目录运行需系统具备 Node.js（或 `node server.js` 直接启动）。

### 1.2 由智能体运行（已安装技能）
技能加载后，在技能包 `app/` 目录执行：
```bash
cd <技能根>/alphasun-beihai-climate/app
PORT=8765 node server.js
```

### 1.3 开发模式（最新源码）
```bash
cd alphasun-beihai-climate/app
node server.js        # 默认端口 8765；改 public/ 后刷新即生效（磁盘优先）
```

## 3. 环境变量
| 变量 | 作用 | 默认值 |
|------|------|--------|
| `PORT` | 服务端口 | `8765` |
| `OPEN` | 启动后是否自动打开浏览器 | `1`（开） |
| `FIRMS_MAP_KEY` | 激活 NASA FIRMS 火点图层 | 未设则火点降级关闭 |
| `NMDIS_APPID` / `NMDIS_APPSECRET` | 激活国家海洋信息中心权威潮汐/水位 | 未设则调和模型估算（演示） |

示例：
```bash
FIRMS_MAP_KEY=xxxx NMDIS_APPID=yyy NMDIS_APPSECRET=zzz PORT=9000 node server.js
```

## 4. 常见问题

**Q1：打开页面是空白 / 灰屏？**
- 底图为高德(Amap) 栅格瓦片，需能访问国内网络；离线环境会降级为 CartoDB/OSM（WGS-84）。
- 确认服务已启动：`curl http://localhost:8765/` 应返回 HTML。

**Q2：叠加卫星云图/雷达没图？**
- nmc 卫星云图（风云 FY2G）与雷达拼图已实测可叠加；其余中央台产品页为 JS 动态渲染，勾选时若取图失败会提示并保留官方原图 `↗` 链接（不伪造坏图）。
- RainViewer / NASA GIBS 随外网可用性降级。

**Q3：火点 / 权威潮汐不显示？**
- 火点需配置 `FIRMS_MAP_KEY`；权威潮汐需配置 `NMDIS_APPID/APPSECRET`；未配置时分别以关闭 / 调和模型估算（演示）兜底。

**Q4：端口被占用？**
- 用 `PORT=新端口 node server.js` 覆盖；或 Windows 用 `netstat -ano | findstr :8765` 查进程并释放。

**Q5：数据多久刷新？**
- 实时 10 分钟自动刷新；界面可手动刷新。部分权威源本身更新频率有限，界面标注「数据时间」。

**Q6：世界时钟不准？**
- 设备时钟若漂移，点「🕒 对时」以服务器时间为基准校准（估算值，受网络时延影响）；未对时显示设备本地时间。机械钟秒针为毫秒平滑扫秒，数字钟毫秒位实时跳动。

## 自动更新（多端）
系统内置版本检查，覆盖所有分发形态：
- **智能体（技能）**：`git pull` 或重新安装技能即更新。
- **Windows / Linux / macOS（exe）**：页脚检测到新版本 → 点「下载 X 版」→ 覆盖原文件即可。
- **安卓 Android（APK）**：页脚提示 → 下载最新 APK → 安装覆盖（版本号自增，无需卸载）。
- **iOS（ipa）**：TestFlight 推送或 Sideloadly 重签安装。
- **网页 / PWA**：服务端资源更新后刷新即生效。
- 检测机制：前端每 30 分钟请求服务端 `/api/latest`（代理 GitHub raw 的 `version.json`）与当前版本比较；页脚「检查更新」可手动触发；无外网静默跳过。
