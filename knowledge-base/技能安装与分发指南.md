# AlphaSun · 北海极端气候全景系统 — 技能安装与分发指南

> 版本 v8.2.0 ｜ 作者：阳光 net2net2net（ Vx: net2net ）｜ 许可：MIT

本系统同时以两种形态交付，均位于共享技能目录 `D:\SynologyDrive\Skills\alphasun-beihai-climate\`：
- **可独立运行的软件**（`app/` 目录，含内置 Node 运行时）
- **可安装的技能**（`SKILL.md` + `INSTALL.md` + `CHANGELOG.md` + `LICENSE`，供其它智能体安装调用）

## 1. 作为独立软件分发（人类用户 / 团队）
1. 将 `alphasun-beihai-climate` 整目录拷贝，或分发 `alphasun-beihai-climate.zip`。
2. 接收方：Windows 双击 `app/dist/AlphaSun.exe`（单文件，约 87MB，需自行构建，见 §4）；或双击 `app/start.bat`；Linux/macOS 执行 `bash app/start.sh`。
3. 自动打开 `http://localhost:8765`。**无需安装 Node.js**（内置 `app/node/node.exe` 或 exe 内含运行时）。

> 适用场景：现场指挥大屏、值班电脑、无开发环境的同事直接运行。

## 3. 跨智能体分发清单
- 技能包目录 `alphasun-beihai-climate/` 自包含（含 `app/` 全部运行文件与 `knowledge-base/` 文档）。
- 安装方式统一为 `cp -r`，无外部依赖，可离线安装。
- 总索引登记：在 `D:\SynologyDrive\Skills\ALPHASUN_INDEX.md` 追加一行：

## 4. 单文件 exe 构建（可选）
exe 因体积（约 87MB）未纳入 git，需要时在 `app/` 目录构建：
```bash
cd app
npm run build:assets      # 将 public/ 内联为 embedded-assets.js
npm i -g pkg              # 安装打包器（首次；或本地 npm i pkg）
npm run build:exe         # 输出 app/dist/（三平台：alphasun-beihai-climate.exe / -linux / -macos）
```
- `build:assets`：把 `public/` 下静态资源 base64 内联，使 exe 单文件可用（磁盘优先、内联兜底）。
- `build:exe`：`pkg . --config package.json`，按 `pkg` 字段（targets: node22-win-x64, outputPath: dist）打包。
- 也可采用 Node SEA（`sea-config.json` + esbuild + `node --experimental-sea`）构建，配置已备。

## 5. 二次开发
- 源码即 `app/`（`server.js` + `lib/` + `public/`），纯 Node.js 零依赖，可直接修改。
- 重新打包：`cp -r` 修改后的 `app/` 回技能包。
- 新增数据源：在 `lib/sources.js` 增加 Adapter，于 `server.js` 聚合；告警在 `lib/alerts.js` / `lib/intel.js` 扩展。
- 前端改 `public/` 后本地 `node server.js` 刷新即生效（磁盘优先）。

## 7. 自动更新（多端）
- **智能体（技能）**：`git pull` 或重新安装技能即更新。
- **Windows / Linux / macOS（exe）**：CI 在推送 `main` 后自动构建并发布到 `downloads/`；页脚检测到新版本 → 点「下载 X 版」→ 覆盖原文件即可。
- **安卓 Android（APK）**：`build-android.yml` 自动构建发布到 `downloads/alphasun-beihai-climate-debug.apk`；页脚提示 → 下载 → 安装覆盖（版本自增）。
- **iOS（ipa）**：`build-ios.yml` 云端产出未签名 IPA → TestFlight / Sideloadly 自签安装。
- **网页 / PWA**：服务端资源更新后刷新即生效。
- 检测机制：前端每 30 分钟请求服务端 `/api/latest`（代理 GitHub raw 的 `version.json`）与当前版本比较；页脚「检查更新」可手动触发；无外网静默跳过。

## 8. 运维提示
- 端口冲突：用 `PORT=新端口 node server.js` 覆盖。
- 日志：独立运行时控制台 / `app/start.sh` 写 `/tmp/alphasun.log`；Windows `start.bat` 开独立窗口显示。
- 数据时效：实时 10 分钟自动刷新；权威源（海洋/干旱）更新频率有限，界面标注数据时间。
