# AlphaSun · 北海极端气候全景系统 — 技能安装与分发指南

> 版本 v7.0.2 ｜ 作者：阳光 net2net2net（ Vx: net2net ）｜ 许可：MIT

本系统同时以两种形态交付，均位于共享技能目录 `D:\SynologyDrive\Skills\alphasun-beihai-climate\`：
- **可独立运行的软件**（`app/` 目录，含内置 Node 运行时）
- **可安装的技能**（`SKILL.md` + `INSTALL.md`，供其它智能体安装调用）

完整文档见本知识库目录 `D:\SynologyDrive\KnowledgeBase\AlphaSun\beihai-climate-panorama\`。

## 1. 作为独立软件分发（人类用户 / 团队）
1. 将 `alphasun-beihai-climate` 整目录拷贝，或分发 `alphasun-beihai-climate.zip`。
2. 接收方：Windows 双击 `app/start.bat`；Linux/macOS 执行 `bash app/start.sh`。
3. 自动打开 `http://localhost:8765`。**无需安装 Node.js**（内置 `node/node.exe`）。

> 适用场景：现场指挥大屏、值班电脑、无开发环境的同事直接运行。

## 2. 作为技能安装（智能体）
安装即把技能目录复制进目标智能体的技能根目录，之后按 `SKILL.md` 的 `description` 触发。

### 2.1 WorkBuddy
```bash
cp -r D:/SynologyDrive/Skills/alphasun-beihai-climate ~/.workbuddy/skills/
```
对话中提及「运行北海气候全景系统」「部署北海极端气候监测面板」等即可触发；技能指导智能体在 `app/` 目录执行 `node server.js`。

### 2.2 Hermes / OpenClaw / 小虾 / ClawHub 兼容
```bash
cp -r D:/SynologyDrive/Skills/alphasun-beihai-climate <目标技能根>/skills/
# 或: clawhub install alphasun-beihai-climate
```

### 2.3 触发信号（description 摘要）
> 「以北海为中心的极端气候/海洋/卫星/天文/空气质量全景监测仪表盘……纯 Node.js 零依赖，已内置便携运行时，支持一键独立运行与跨智能体安装。」

## 3. 跨智能体分发清单
- 技能包目录 `alphasun-beihai-climate/` 自包含（含 `app/` 全部运行文件）。
- 安装方式统一为 `cp -r`，无外部依赖，可离线安装。
- 总索引登记：在 `D:\SynologyDrive\Skills\ALPHASUN_INDEX.md` 追加一行：
  `| alphasun-beihai-climate | cp -r D:/SynologyDrive/Skills/alphasun-beihai-climate <目标技能目录>/ |`

## 4. 二次开发
- 源码即 `app/`（`server.js` + `lib/` + `public/`），纯 Node.js 零依赖，可直接修改。
- 重新打包：`cp -r` 修改后的 `app/` 回技能包，或在 `E:\SD\...\alphasun-weather` 开发后重新同步。
- 新增数据源：在 `lib/sources.js` 增加 Adapter，于 `server.js` 聚合；告警在 `lib/alerts.js` / `lib/intel.js` 扩展。

## 6. 运维提示
- 端口冲突：用 `PORT=新端口 node server.js` 覆盖。
- 日志：独立运行时控制台 / `app/start.sh` 写 `/tmp/alphasun.log`；Windows `start.bat` 开独立窗口显示。
- 数据时效：实时 10 分钟自动刷新；权威源（海洋/干旱）更新频率有限，界面标注数据时间。
