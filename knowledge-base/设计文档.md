# AlphaSun · 北海极端气候全景系统 — 设计文档

> 作者：阳光 net2net2net（ Vx: net2net ）｜ 版本：v7.0.2 ｜ 适用：北海防风防汛 / 防灾应急

## 1. 目标与范围

### 1.1 建设目标
构建覆盖北海全域（海城 / 银海 / 铁山港 / 合浦 / 涠洲岛）的极端气候全景系统，实现：
1. **全方位权威实时天气**：陆地气象 + 空气质量（AQI/六项污染物）+ 海洋（潮汐/水位/海浪/风暴潮）+ 卫星（云图/红外）+ 天文（日出日落/月出月落/月相/晚霞概率/天文景观）。
2. **周期预报**：7 日趋势 + 24 小时逐时曲线。
3. **极端天气告警**：地震、汛情、干旱、高温、台风、野火等多灾种分级告警与处置建议。
4. **地图全景**：以地图为底座，按风险等级着色，叠加卫星云图、火点、台风路径。

### 1.2 设计原则
- **权威优先**：优先国家级业务单位数据源（气象、海洋、地震、水利、卫星）。
- **多源冗余**：每类数据至少 1 主源 + 1 备源，主源不可用时自动切换。
- **合规安全**：地图采用 GCJ-02 合规底图；密钥不下发前端；满足等保与数据安全要求。
- **可落地**：以已验证可用的开放 API 为核心，减少定制化抓取的法律与运维风险。

## 2. 总体架构
```
展示层（Dashboard / 大屏）
  实时全景区 │ 海洋天文区 │ 卫星云图区 │ 周期预报区 │ 告警区 │ 地图区
        │ HTTP
服务层（聚合 / 研判 / 推送）
  数据源抽象层(Adapter) │ 极端天气研判引擎(规则引擎) │ 多源 Failover & 缓存 │ 告警分级
        │ 定时拉取
数据层（权威数据源，主 + 备）
  陆地 │ 海洋 │ 卫星 │ 天文 │ 地震 │ 汛情 │ 干旱 │ 台风 │ 野火
```

**技术选型**
- 前端：原生 JS + Leaflet（地图）+ Chart.js（图表），暗色主题，无构建。
- 服务层：Node.js 聚合代理，隐藏密钥、解决 CORS、多源切换、缓存。
- 缓存：进程内 `climateCache` Map（热点缓存）；可选 Redis / 时序库归档。

## 3. 数据域与权威源矩阵
> ✅ = 本次已实测可用；⚠️ = 官网/业务系统为主，自动化需评估合规与资质。

| 数据域 | 主源 | 状态 |
|---|---|---|
| 陆地气象 + 天文 | Open-Meteo Forecast | ✅ 实时 |
| 空气质量 AQI / 六项 | Open-Meteo Air Quality（Copernicus CAMS） | ✅ 实时 |
| 海洋 浪高 / 海温 | Open-Meteo Marine | ✅ 实时 |
| 洪涝 河流流量 | Open-Meteo Flood（GloFAS） | ✅ 实时 |
| 地震 | USGS GeoJSON | ✅ 实时 |
| 台风实时路径 / 气象预警 | 中央气象台（nmc） | ✅ 实时 |
| 黄昏霞光概率 | 云量/降水/湿度/风 模型（服务端计算） | ✅ |
| 天文景观日历 | 流星雨/超级月亮/银河（服务端计算） | ✅ |

## 4. 极端天气告警体系

### 4.1 风险分级
| 等级 | 名称 | 颜色 | 含义 |
|---|---|---|---|
| 0 | 正常 | 🟢 | 无极端风险 |
| 1 | 注意 | 🔵 | 一般关注（5 级风、有降水、雾） |
| 2 | 预警 | 🟡 | 需加强巡视（6 级强风、大雨、高温） |
| 3 | 警报 | 🟠 | 启动专项预案（8 级大风、暴雨、雷暴、酷热、风暴潮） |
| 4 | 紧急 | 🔴 | 全面应急（10 级+ 台风、大暴雨、雷暴冰雹） |

### 4.2 研判规则引擎（可配置）
每类数据源进入规则引擎，按阈值产生告警 `{level, label, advice, value, source}`。示例（陆地）：
- **风**（m/s）：≥32.7→紧急；≥24.5→紧急(台风级)；≥17.2→警报；≥10.8→预警；≥8.0→注意
- **阵风**：≥32.7→紧急；≥24.5→警报；≥13.9→预警
- **短时降水**（mm/h）：≥8→警报；≥3→预警
- **日累计降水**（mm）：≥100→紧急；≥50→警报；≥25→预警
- **高温**（℃）：≥37→警报；≥35→预警
- **低温**（℃）：≤5→警报；≤8→预警
- **低气压**（hPa）：≤995→警报（热带气旋征兆）
- **强对流**：雷暴(95/96/99)+大风→警报；雷暴伴冰雹→紧急

### 4.3 北海关联研判（v7.0.0 核心）
- `region`：北海 / 广西 / 其他（行政归属）
- `beihaiRelation`：`direct`（涉及北海）/ `possible`（可能涉及北海）/ `none`（无）
- 距北海：Haversine（`distBH`）+ `fmtDist`，台风/地震/火点/预警均显示「距北海约 X km」
- 优先排序：北海(rank0) ▸ 广西(rank1) ▸ 其他(rank2)，再按等级、时间

## 5. 地图方案

### 5.1 底图合规
- 演示：Leaflet + 高德(Amap) 栅格瓦片（GCJ-02，免密钥），所有 WGS-84 数据做 WGS-84→GCJ-02 纠偏后绘制。
- 生产：须注册天地图 / 高德 Key（GCJ-02 合规），完成坐标纠偏。

### 5.2 图层
| 图层 | 形式 | 数据源 |
|---|---|---|
| 监测站点 | 分级着色 circleMarker | 各站点实时研判等级 |
| 真实边界 | GeoJSON MultiPolygon（DataV 450500，含涠洲岛） | 北海市 4 区 + 涠洲岛 |
| 卫星云图 / 雷达 | imageOverlay（中央气象台代理，绕开防盗链） | 风云 FY2G 云图 / 雷达拼图（实测可叠加） |
| 火点 | 叠加层 | NASA FIRMS（需密钥） |
| 台风路径 | polyline + 风圈 | 中央气象台 |
| 潮汐 / 水位站 | 标注 + 时序弹窗 | 国家海洋信息中心 |
| RainViewer / NASA GIBS | 瓦片叠加（随外网可用性降级） | 雷达 / 卫星 |

> 叠加层可用性：中央气象台部分产品页（降水/风力/副高/海浪/扰动）为 JS 动态渲染且带防盗链，服务端无法稳定抓取栅格；此类勾选时若取图失败会提示并保留官方原图链接（不伪造坏图）。

## 7. 风险与合规
1. **资质与合规**：国家海洋/地震/台风/水利等国家级业务系统多为官网发布，自动化接口需评估数据使用协议与资质。
2. **密钥申请**：NMDIS appid/appsecret、FIRMS MAP_KEY、天地图 tk 需提前申请。
3. **地图合规**：生产必须替换为天地图/高德等合规底图，并完成坐标纠偏。
4. **等保与数据安全**：服务端聚合层需满足信息安全要求，密钥与日志受控。
5. **数据时效性**：部分权威源更新频率有限（潮汐为预报、干旱为日/旬值），界面须明确「数据时间」。
